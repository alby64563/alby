# Alby Portfolio

Welcome to the Alby Portfolio project! This repository contains the source code for a personal portfolio website showcasing projects and skills.

## Project Structure

```
alby-portfolio
├── src
│   ├── index.html       # Main HTML document for the portfolio website
│   ├── styles.css       # Styles for the portfolio website
│   ├── script.js        # JavaScript code for interactivity
│   └── data
│       └── projects.js  # Data file containing project details
├── public
│   └── favicon.svg      # Favicon for the website
├── package.json         # npm configuration file
└── README.md            # Project documentation
```

## Features

- Responsive design that works on various devices
- Interactive elements powered by JavaScript
- Dynamic project loading from a data file
- Custom favicon for branding

## Setup Instructions

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/alby-portfolio.git
   ```

2. Navigate to the project directory:
   ```
   cd alby-portfolio
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Open `src/index.html` in your browser to view the portfolio.

## Usage Guidelines

- Modify the `src/data/projects.js` file to update or add new projects.
- Customize styles in `src/styles.css` to change the appearance of the website.
- Use `src/script.js` to add or modify interactivity.
